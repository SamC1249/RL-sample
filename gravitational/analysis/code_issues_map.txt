Problem Analysis:
    - Near black hole (mass=1e8, G=1e-3), at distance r=10:
      ||g|| = G * m / r² = 1e-3 * 1e8 / 100 = 1,000
    
    - Gravity cost per step: 1,000 * (1 - cos θ)
      Best case (perfect alignment): 0
      Worst case (perpendicular): 1,000
      Average case: ~500
    
    - Thrust reward per step: k * T = 0.1 * 1.0 = 0.1
    
    - Ratio: Gravity cost is 5,000x to 10,000x larger!

Fix Option A - Normalize gravity cost:
    def _compute_reward(self, thrust_direction, thrust_magnitude, gravity_vector):
        g_magnitude = np.linalg.norm(gravity_vector)
        
        if g_magnitude > 1e-6:
            g_direction = gravity_vector / g_magnitude
            cos_theta = np.dot(thrust_direction, -g_direction)
            # Normalize to [0, 1] range using tanh
            gravity_cost = np.tanh(g_magnitude * (1 - cos_theta) / 100.0)
        else:
            gravity_cost = 0.0
        
        thrust_reward = 1.0 * thrust_magnitude  # Increased k to 1.0
        reward = -gravity_cost + thrust_reward
        return reward

Fix Option B - Add reward shaping:
